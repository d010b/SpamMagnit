# SpamMagnit — Android - активатор спам звонков.

Android-минималистическое приложение для активации спам звонков на номер телефона, используемый для выхода в интернет через оператора сотовой связи. 
Речь о технологии, которая позволяет оператору связи (через LTE-сеть) в момент вашего визита на сайт передать ваш номер телефона в рекламную систему без единого действия с вашей стороны.

## Принцип работы
Проект иллюстрирует практику которая нарушает законодательство о персональных данных. Ваше устройство, выходя в интернет через LTE, получает публичный IP-адрес от оператора связи. Этот IP-адрес в данный момент времени однозначно привязан к вашему номеру телефона в базах оператора (через IMSI и MSISDN)

Когда вы загружаете страницу сайта, этот сайт (или установленный на нём скрипт-аналитики) отправляет запрос не оператору напрямую, а в специализированный сервис — AdTech-платформу, которая имеет договор с вашим оператором. В запросе передаётся ваш IP-адрес.

Сервис обращается к оператору с вопросом: «Какой номер телефона соответствует этому IP-адресу в данный момент?» Оператор, если это предусмотрено его договорами и настройками, возвращает ответ. Технически это реализуется через компонент в сети оператора, который умеет по публичному IP находить реальный идентификатор абонента (IMSI или MSISDN)

Ваш номер попадает в рекламную систему. Без звонка. Без формы. Без вашего прямого согласия.

Есть мнение что в рекламных сервисах, связанных с операторами, можно по одному звонку или переходу по ссылке собрать подробный цифровой профиль — геолокацию, интересы, данные о звонках, сообщениях и даже семейном статусе.

Приложение не выявляет механизмы задействованные в коммерческой утечке номера телефона, а лишь активирует их простым перебором. В настоящее время отсутствует механизм, который сам по себе доказывал бы передачу номера телефона оператором рекламной системе.

Результатом работы приложения станет активация спам звонков до 300 ед в первые сутки с дальнейшим уменьшением активности.

Результат может быть использован для тестирования спам защиты, сбора номеров спам-центров, формирования регулярных жалоб на спам в компетентные органы для борьбы с явлением.

Приложение работает в три этапа:

### Этап 1 — Сбор доменов
Для каждого IP-адреса из списка (33 адреса) запрашивает связанные с ним домены(33 IP это константа, выбраны случайным образом по количеству доменов из разных хостингов).

### Этап 1.5 — Сортировка и фильтрация
Собранные домены проходят очистку:
- Приведение к нижнему регистру и обрезка пробелов
- Удаление дубликатов
- Отбрасывание IP-адресов
- Фильтр по российским зонам
- Удаление и группировка по apex и ограничение на один apex.

### Этап 2 — Посещение домена (ориентировочно около 100k доменов)
Для каждой пары `(IP, домен)` выполняется проверка:
1. Сначала **HTTPS** через `https://domain/`
2. Если HTTPS не удался — **HTTP** через `http://domain/`

Ответ считается успешным, если получен любой HTTP-код (включая 4xx/5xx) и прочитано несколько байт тела. Тело ограничено 16 КБ, чтобы не тянуть большие страницы.

## Возможности

- **Асинхронный сбор доменов** — 2 IP обрабатываются параллельно, до 12 проверок сканирования одновременно
- **Кэш ответов** — результаты сбора доменов сохраняются на 24 часа, что ускоряет повторные запуски
- **Foreground Service** — работа в фоне с уведомлением и кнопкой «Стоп»
- **WakeLock** — предотвращает засыпание устройства во время сканирования, продлевается каждые 10 минут
- **Лог в реальном времени** — последние 20 проверок с цветовой индикацией (HTTPS/HTTP/FAIL)
- **Обработка отмены** — корректная остановка по кнопке «Стоп» без потери прогресса
- **Адаптивная фильтрация** — исключение поддоменов и ограничение на apex

### Требования
- **Android 7.0+** (API 24) — минимальная версия
- **Android 14** (API 34) — целевая версия
- Разрешения: `INTERNET`, `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_DATA_SYNC`, `POST_NOTIFICATIONS`, `WAKE_LOCK`
- Мобильный траффик не менее 1,3 gb
- Время в размере от 2-5 часов
- Подключенное зарядное устройство

### Известные ограничения
- Отключена проверка SSL-сертификатов. Это сделано осознанно для проверки reachability, и не нужно приложению так как оно не обрабатывает и не сохраняет полученный траффик.
- Разрешен cleartext-трафик (android:usesCleartextTraffic="true") для проверки HTTP-доступности.
- Низкий процент "живых" доменов в ru-зоне.
